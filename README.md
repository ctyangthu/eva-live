# 長榮航空航班動態系統

依長榮航空 2026/27 冬季（NW26）國際線班表，在世界地圖上推算每一個航班的位置，並提供桃園、松山、清泉崗、高雄的出發／抵達看板、時刻表、航線網路與資料查核。

網址：https://ctyangthu.github.io/eva-live/

三家合併的系統：https://ctyangthu.github.io/air-live/

以 2026/11/9–11/15 這一週為例，自臺灣出發 602 班自營航班（長榮 591、立榮 11），加上他航共掛 212 班：

| 機場 | 長榮自營 | 立榮自營 | 他航共掛 | 自營航點 |
|---|---:|---:|---:|---|
| 桃園 TPE | 513 | 5 | 156 | 48 個（立榮：深圳） |
| 松山 TSA | 24 | 6 | 19 | 羽田、虹橋、金浦（立榮：浦東、廈門） |
| 清泉崗 RMQ | 0 | 0 | 14 | 沒有自營；澳門由澳門航空執飛 |
| 高雄 KHH | 54 | 0 | 23 | 成田、關西、福岡、仁川、香港、澳門、浦東 |

## 查核結果（2026/11/4）

比對官網 273 頁、3,121 個航班日（其中 733 個是共掛）與四座機場 1,305 筆：長榮與立榮自營航班**沒有遺漏，也沒有多列**（機場資料未收錄的 2 筆是函館包機）。

這個系統原本缺的是下面這些，已補入：

| 航班 | 航段 | 說明 |
|---|---|---|
| B7187／188 | 桃園—深圳 | 立榮，週一二四五日 |
| B7501／502 | 松山—上海浦東 | 立榮，週二四日 |
| B7511／512 | 松山—廈門 | 立榮，週一三五 |
| BR3497–3500 | 清泉崗—澳門 | 澳門航空執飛，長榮在清泉崗唯一的國際航班 |
| BR2xxx、BR3xxx、B77xxx | 四座機場共 16 個航點 | 他航共掛，預設隱藏 |

也修正了自營航班的時刻：北京 BR716／715 依星期有三種時刻，釜山 BR164／163 與 BR194／193、福岡 BR104 依星期不同，大阪 BR132 自 11/9 改時刻，巴黎、米蘭、慕尼黑、維也納自 12/1 抵達時間延後，北美線依美國夏令時間分成兩行。

## 功能

- **三類航班可切換**：長榮自營、立榮自營（預設顯示）、他航共掛（預設隱藏）。查詢共掛班號（如 BR3497）會自動打開共掛。
- **依日期套用班表**：每個航段記錄行駛星期與期間，各機場時區與日光節約時間由瀏覽器換算，所以同一班機在不同日期的臺北時間會跟著變。德里航線 2026/12/1 首航、桃園—釜山 BR194/193 自 2027/1/2 起，也依日期判斷。同一航班依星期或期間有不同時刻時（如北京 BR716/715、歐洲線 12/1 起的抵達時間）分開列出。
- **即時與模擬**：預設使用現在時間；可切換日期、拖曳時間軸（臺北時間），並以 1×–3600× 播放。前一兩天起飛、仍在空中的長程航班會繼續顯示。
- **地圖**：Miller 投影、以東經 143° 為中心，倫敦到紐約一張圖看完。航線依大圓繪製並以區域上色，飛機沿大圓航線移動、機頭朝行進方向；陰影為當下的夜間區域。可拖曳縮放，並有全航網、亞太、東北亞、東南亞、歐洲、北美等範圍；圖例可逐一顯示或隱藏各區域。
- **航班詳情**：起降時間（當地與臺北時間）、飛行進度、推算地速與高度、已飛與剩餘距離、行駛星期；經停曼谷的 BR61/62、BR67/68、BR75/76 會列出兩個航段。
- **出發／抵達看板**：依桃園、松山、清泉崗、高雄篩選本日航班，狀態依時刻表推算（預定、即將起飛、已起飛、飛行中、即將抵達、已抵達）。
- **空中**：目前在空中的航班，分為從臺灣出發與飛往臺灣，依剩餘時間排序。
- **時刻表**：依航點分組，可依區域、航班號或城市搜尋，標示本日不飛與正在飛行的航段。
- **航點**：各區域航點、每週班次與最短飛行時間；點選航點會在地圖上標出航線並帶出時刻表。
- **查核**：四座機場的班次與航點、這次補入的航班、與官網和機場資料的比對範圍。

## 限制

- 航班狀態與位置依表定時間推算（扣除約 14 分鐘滑行出發、6 分鐘滑行抵達，沿大圓航線移動），不含延誤、取消、改降等即時資訊；實際航路會因空域與風向繞行，兩岸航線尤其明顯。
- **官網是抽查，不是逐週全掃。** 全部航線去回程查過 12/28–1/3；2/1–2/7 查桃園部分航線與松山、高雄、清泉崗；3/15–3/21 查全部北美線與代表航線；時刻有差異的航線另查 11/9–12/20、1/4–1/17 的數週。未查的週次依前後規律推定。
- 北美線夏令時間的切換日依 2027/3/14 推定；巴黎 BR87 起飛改回 23:30 的日期也是推定。
- 共掛航班由他航排班，班期與時刻只是代表值；香港航空、澳門航空的部分班次 11 月不是每天飛。BR3501／3502 伊斯坦堡第二班只收查到的 12/28–1/3。
- 不含包機（旭川 BR136/135、函館 BR138/137）：不在官網時刻表，只有桃園機場 11/3 看得到函館，日期不明。
- 同一航班常輪替機型，班表記錄的是 2026/11/2–12/1 期間執飛天數最多的機型。
- TDX 需要金鑰才能查長榮，這次沒有使用。官網資料是在瀏覽器裡以一般查詢方式低頻讀取，所以無法自動更新。
- 超出 2026/10/25–2027/3/27 的日期沒有班表可推算，頁面會提示。
- 本系統為非官方展示，與長榮航空無關，實際航班請以長榮航空公告為準。

## 專案結構

```
src/app.html                網頁原始碼（資料以佔位字串嵌入）
data/schedule-nw26.txt      班表：每行一個航段（航班、起訖、當地時間、星期、機型）
data/airports.json          63 個機場：中英文名稱、區域、座標、IANA 時區
data/audit-airports.json    與機場資料的比對結果（由 audit_airports.py 產生）
data/audit-notes.json       查核分頁的內容（手動維護）
data/map.json               投影並簡化後的陸地、國界與臺灣路徑
tools/schedule.py           解析 schedule-nw26.txt
tools/check_schedule.py     以時區換算飛行時間，檢查 +1/+2 與時刻是否合理
tools/audit_airports.py     與桃園、松山、高雄、清泉崗機場公布的航班比對，找出缺漏與時刻差異
tools/build_map.py          由 Natural Earth 1:50m（world-atlas）產生 data/map.json
tools/build.py              組出 dist/index.html
```

## 建置

```bash
python3 tools/build.py
```

產出的 `dist/index.html` 可直接用瀏覽器開啟。推送到 `main` 後，GitHub Actions 會自動建置並部署到 GitHub Pages。

修改班表後先檢查再建置（`audit_airports.py` 只看得到機場當下公布的日期，宜在不同星期各跑一次）：

```bash
python3 tools/check_schedule.py
```

```bash
python3 tools/audit_airports.py
```

```bash
python3 tools/build.py
```

重新產生地圖時，先下載 [land-50m.json](https://cdn.jsdelivr.net/npm/world-atlas@2.0.2/land-50m.json) 與 [countries-50m.json](https://cdn.jsdelivr.net/npm/world-atlas@2.0.2/countries-50m.json)，再執行：

```bash
python3 tools/build_map.py land-50m.json countries-50m.json
```
